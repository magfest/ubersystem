Overflow Booking

Early overflow-hotel booking links for lottery entrants who got no room. Each recipient gets a personal Uber link by email; the page shows a countdown and reveals the booking links at the reveal time. The Uber link records clicks; it refuses a forwarded link only when sign-in is required. Once revealed, the hotel URLs can be shared like any web page, so the head start lasts only until they spread or are posted publicly.
